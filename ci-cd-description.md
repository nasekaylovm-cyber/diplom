CI/CD пайплайн для проекта Bootstrap CMS с использованием GitHub Actions
_________________________________________________________________________________________________________________________________________________________
Анализ проекта и выбор инструментов.

Проект Bootstrap CMS— это система управления (веб-приложение) контентом с открытым исходным кодом (Open-Source), созданная на основе фреймворка Bootstrap 
Система использует Eloquent ORM для работы с MySQL/PostgreSQL/SQLite.
Применяемый стек технологий: PHP (Laravel), JavaScript, CSS, HTML. 
_________________________________________________________________________________________________________________________________________________________

Для создания CI/CD пайплайн выбрана платформа GitHub Actions, что обусловлено простота использования широким набором готовых действий (Actions), что ускоряет разработку пайплайнов, а также отсутствием географических ограничений на использование возможностей платформы.
_________________________________________________________________________________________________________________________________________________________

С учетом анализа информации содержащейся в репозитории Bootstrap CMS, определен перечень инструментов, которые предполагается использовать:

CI/CD

Инструмент GitHub Actions – платформа для автоматизации процессов непрерывной интеграции и доставки (CI/CD), полностью интегрированная с экосистемой GitHub, позволяет управлять автоматизированной сборкой и тестированием при каждом изменении кода, управлять сканированиями безопасности (SAST, DAST, Secret Scanning), управлять процессами развертывания на staging и production окружения, координировать все этапы безопасной доставки кода
____________________________
Стадия SAST – статический анализ

Инструмент:

Semgrep — это статический анализатор для поиска шаблонов в коде, позволяет выявлять уязвимости в исходном коде, в том числе PHP и JavaScript, обнаруживать несоответствия кода лучшим практикам, потенциальные уязвимости OWAST TOP 10. 
Поддержка обширного спектра языков программирования, в том числе PHP, JavaScript, TypeScript, не требует компиляции проекта, большой перечень правил безопасности, постоянная поддержка и обновления.  
TruffleHog - специализированный инструмент для обнаружения секретов, случайно закоммиченных в репозиторий, такие как API keys (AWS, GitHub, Stripe, etc.), пароли и токены доступа, криптографические ключи, конфигурационные файлы с чувствительными данными.
____________________________
Стадия DAST - динамический анализ 

Инструмент:

OWASP ZAP (Zed Attack Proxy) — это динамический сканер безопасности веб-приложений, который позволяет производить тестирование работающего приложения на уязвимости, в том числе: автоматическое сканирование всех доступных точек, выявлять в режиме реального времени уязвимости из OWASP TOP 10(XSS, SQLi, CSRF), проверять конфигурации безопасности сервера, автоматически формировать отчеты.
